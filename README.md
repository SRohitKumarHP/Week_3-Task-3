# Week_3-Task-3
Contour, Object analysis Programs detecting the No of objects and displaying measurements in px

First, download all these programs into a single folder.
Open a new terminal for the location of all these programs.
Install the required libraries:
  pip install opencv-python 
  pip install numpy
Simply run the programs in the terminal:
  bash: python <file_name>

There is no particular document structure for this task all the programs are required to be in one single Folder.
